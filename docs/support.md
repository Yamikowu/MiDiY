# 支援範圍

本頁集中維護控制器輸入、執行平台、MIDI 輸出及接收端支援；協定與細部證據連至裝置文件及日期紀錄。

## 狀態怎麼讀

- **已實作**：已有程式，未必完成實機驗證；部分實作須列出範圍。
- **已驗證**：有日期、條件與證據，程式／瀏覽器／實機分開記錄。
- **研究假說**：觀察或推論尚待重現，不列為已確認的支援。
- **未實作／未來規劃**：尚未提供；候選裝置與平台不代表已支援。

## MIDI 輸出與接收端

| 執行平台 | 輸出方式 | 實作狀態 | 接收端證據 |
| --- | --- | --- | --- |
| 網頁 | Web MIDI 選定系統輸出埠 | 已實作 | 歷史 Logic Pro Virtual In、IAC bus／Koala 見[紀錄](verification/2026-10-19.md) |
| 樹莓派，機型未定 | 有線 MIDI，方式待選 | 未實作 | 無 |

| 樹莓派／ESP32 | BLE MIDI | 未實作 | 無 |

Windows、macOS、iPhone、iPad、Android、Linux 或其他接收設備的支援，必須依實際輸出方式、OS 版本、接收軟體、配對／連線步驟與結果逐項記錄。目前歷史紀錄沒有完整 OS／App 版本，不推論為整個平台已驗證。

BLE MIDI 封裝與連線屬輸出 Adapter，控制器輸入是否使用藍牙是另一個問題。網頁部署管理通道也與 MIDI 輸出分開。本輪未實作網頁直連 BLE MIDI 或盒子輸出。
