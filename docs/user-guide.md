# MiDiY 網頁操作指南

本頁說明目前網頁的共用操作流程。目前僅實作 Mikro MK3；控制項、預設映射、力度與回饋能力依裝置定義，請另看 [Mikro 操作指南](devices/mikro-mk3/user-guide.md)與[支援範圍](support.md)。

## 介面語言

裝置名稱右側的「繁中／EN」可切換繁體中文與英文。初次依瀏覽器偏好選擇支援語言，未匹配時使用繁中；手動選擇會記住在此瀏覽器。切換只更新顯示文字，不重新連線或清除映射草稿、擷取狀態與備註。設定檔／模式名稱及使用者輸入維持原文。

## 連接裝置

以支援 WebHID／Web MIDI 的桌面 Chromium 開啟 `http://127.0.0.1:4173`，按「連接裝置」授權目前支援的控制器，之後會重用已授權的裝置。一般遠端 HTTP 不提供 WebHID 所需的安全環境。目前這是 WebHID 連線流程，其他輸入方式尚未實作。

## 兩個工作區

- **Mapping**（`/#mapping`）：點控制器參照圖選取控制項，編輯 MIDI 動作、模式及裝置提供的回饋設定。
- **Testing**（`/#testing`）：逐項擷取、即時解碼、查看原始封包，並匯出 Session JSON 或候選 CSV。

兩頁各自保留選取狀態。切換頁面不會重新連線、丟失表單草稿或中止擷取；即時轉譯繼續運作。Testing 的 Session 與 Mapping 的設定檔使用不同格式和匯入／匯出按鈕。

## 映射與 MIDI 輸出

1. 點「授權 MIDI」，選擇接收端的 MIDI 輸出埠；選「停用 MIDI 輸出」可只看解碼預覽。
2. 在 Mapping 點控制器參照圖，設定該控制項可用的動作。
3. 按「套用至目前模式」，更新執行設定並自動儲存整份設定檔。

控制項表單的修改在套用後才保存；切換控制項前會提示未套用的草稿。匯出時會先驗證並套用目前控制項的草稿。裝置專屬的預覽、立即儲存選項與回饋接管方式，見各裝置操作指南。

## Note 編號與音名

控制項編輯器的「音名八度對照」可選 Note 60 = C3、C4（預設）或 C5；「音符輸入方式」可選 Note 編號或音名。Note 編號輸入 0–127 並顯示音名；音名以音高及八度選擇，旁邊顯示 MIDI 編號。最高八度只開放 MIDI 可表示的音符。

這兩個選項適用所有 Note 欄位，包括 Pad Hit、Pad Press、按鍵及 Strip 的 Note／Poly Pressure，也適用多選編輯。混合值維持未指定；選完音名與八度才產生批次修改。Pad 與控制項摘要同時顯示音名及編號。

切換輸入方式、八度對照或介面語言不會移調、不會套用草稿，也不會中斷連線或發送 MIDI／LED。只有實際修改音符選擇才會改變草稿的 MIDI 編號；仍需按「套用至目前模式」。若接收軟體顯示的八度不同，調整八度對照即可，應以相同 MIDI 編號核對。

偏好獨立記在此瀏覽器（`midiy-note-preferences-v1`），不包含在 Profile；Profile 與實際輸出仍使用數字 0–127。更換 Profile 不會更換這兩個偏好。

## 設定檔與模式

頂部兩列分別選擇設定檔和模式。按「編輯」可改名、儲存或刪除；「複製」建立獨立副本並進入命名狀態。按 Escape 可放棄尚未儲存的名稱。「設為啟動模式」決定下次載入此設定檔時選用的模式。

匯出會下載可攜 JSON；匯入會儲存為本機的新設定檔，不包含 MIDI 輸出埠或瀏覽器物件。目前 Profile 仍是 [Mikro 專用格式](devices/mikro-mk3/profile.md)，不代表已支援跨裝置載入。

## 擷取與研究

在 Testing 選取控制項，依提示操作實體控制器，按「開始擷取」及「停止並分析」保存樣本與候選欄位。操作備註可補充當時動作與裝置狀態；候選只表示有變化，需重複操作確認協定。

原始資料最多保留 100,000 筆，畫面顯示最近 100 筆。「暫停顯示」或「清除顯示」不刪除 Session，也不中止 MIDI 轉譯。Session 不會自動儲存，重新整理前先匯出；匯入會取代目前 Session。格式與限制見[開發指南](development.md#capture-session目前-hid-擷取格式)。

## 音符釋放

目前網頁在切換模式、套用設定、切換 MIDI 埠或控制器斷線時，會釋放相關音符與按住的 CC；「Panic」可主動釋放目前狀態。重新整理也會嘗試釋放。實體 MIDI 埠消失時，最後的 Note Off 可能無法送達；若仍有聲音，請使用接收軟體的 Panic。

MiDiY 不會建立虛擬 MIDI 埠或修改接收 App 的 MIDI map。接收端方式與驗證範圍見[支援表](support.md#midi-輸出與接收端)，Mikro 的 Logic Pro／Koala 設定範例見[裝置指南](devices/mikro-mk3/user-guide.md#midi-接收端範例)。
