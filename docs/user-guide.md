# MiDiY 網頁操作指南

本頁說明目前網頁的共用操作流程。目前僅實作 Mikro MK3；控制項、預設映射、力度與回饋能力依裝置定義，請另看 [Mikro 操作指南](devices/mikro-mk3/user-guide.md)與[支援範圍](support.md)。

## 介面語言

固定於頂端的導覽列右側「繁中／EN」可切換繁體中文與英文。初次依瀏覽器偏好選擇支援語言，未匹配時使用繁中；手動選擇會記住在此瀏覽器。切換只更新顯示文字，不重新連線或清除映射草稿、擷取狀態與備註。設定檔／模式名稱及使用者輸入維持原文。

## 連接裝置

以支援 WebHID／Web MIDI 的桌面 Chromium 開啟 `http://127.0.0.1:4173`，按「連接裝置」授權目前支援的控制器，之後會重用已授權的裝置。一般遠端 HTTP 不提供 WebHID 所需的安全環境。目前這是 WebHID 連線流程，其他輸入方式尚未實作。

## 兩個工作區

- **Mapping**（`/#mapping`）：點控制器參照圖選取控制項，編輯 MIDI 動作、模式及裝置提供的回饋設定。
- **Testing**（`/#testing`）：逐項擷取、即時解碼、查看原始封包，並匯出 Session JSON 或候選 CSV。

兩頁各自保留選取狀態。切換頁面不會重新連線、丟失表單草稿或中止擷取；即時轉譯繼續運作。Testing 的 Session 與 Mapping 的設定檔使用不同格式和匯入／匯出按鈕。

MIDI 授權／輸出與 Panic 在底部狀態列左側，連線狀態、LED 接管、「連接裝置」與「中斷」在右側；窄視窗分兩列。上下列沿用相同底色、內容寬度與左右邊界。狀態右側燈泡圖示切換 LED 接管，亮起表示已接管，懸浮顯示說明與目前狀態；未連線或裝置不支援時停用。捲動或切換 Mapping／Testing 時仍可操作。

## 映射與 MIDI 輸出

1. 點「授權 MIDI」，選擇接收端的 MIDI 輸出埠；選「停用 MIDI 輸出」可只看解碼預覽。
2. 在 Mapping 點控制器參照圖，設定該控制項可用的動作。
3. 按「套用至目前模式」，更新執行設定並自動儲存整份設定檔。

Pad 的 Hit／Press、Strip 的 Position／Touch 使用控制項編輯器內的分頁。切換分頁不套用或清除草稿；Pad 色彩與 Strip 燈光維持在分頁下方共用，按「套用至目前模式」一次保存兩邊映射與共用燈光。多 Pad 選取也提供 Hit／Press 分頁；一般按鍵及旋鈕不顯示這組分頁。若未顯示的分頁有無效欄位，驗證時會切到該分頁以便修正。

控制項表單的修改在套用後才保存；切換控制項前會提示未套用的草稿。匯出時會先驗證並套用目前控制項的草稿。裝置專屬的預覽、立即儲存選項與回饋接管方式，見各裝置操作指南。

## Note 編號與音名

參照圖下方的「音名八度對照」可選 Note 60 = C3、C4（預設）或 C5；「音符輸入方式」可選 Note 編號或音名。Note 編號輸入 0–127 並顯示音名；音名以音高及八度選擇，旁邊顯示 MIDI 編號。最高八度只開放 MIDI 可表示的音符。這組顯示偏好只在目前選取控制項的映射表單含 Note／Poly Pressure 等音符欄位時顯示，含 Hit、Press、Strip Touch 與多選編輯。

這兩個選項適用所有 Note 欄位，包括 Pad Hit、Pad Press、按鍵及 Strip 的 Note／Poly Pressure，也適用多選編輯。混合值維持未指定；選完音名與八度才產生批次修改。Pad 與控制項摘要同時顯示音名及編號。

切換輸入方式、八度對照或介面語言不會移調、不會套用草稿，也不會中斷連線或發送 MIDI／LED。只有實際修改音符選擇才會改變草稿的 MIDI 編號；仍需按「套用至目前模式」。若接收軟體顯示的八度不同，調整八度對照即可，應以相同 MIDI 編號核對。

偏好獨立記在此瀏覽器（`midiy-note-preferences-v1`），不包含在 Profile；Profile 與實際輸出仍使用數字 0–127。更換 Profile 不會更換這兩個偏好。

## 設定檔與模式

頂部兩列分別選擇 Profile 和要編輯的 Mode；Mode 旁的「演奏：…」表示 Runtime 實際正在使用的模式。切換上方 Mode 選單只更換編輯對象，不切換實際演奏模式或送 MIDI／HID。Profile 右側的力度曲線套用至整份設定檔；Mode 列的「啟動模式」決定下次載入此設定檔時選用的模式，每份設定檔只有一個啟動模式，請切換到另一個模式勾選以取代。

兩列都有鉛筆（編輯）、複製圖示與「＋」，懸浮提示及可存取名稱保留中英文。按「編輯」後，選單原地切換成名稱輸入框；綠色 ✔／Enter 儲存名稱，原色 ✕／Escape 取消改名，紅色刪除圖示確認後刪除。改名不會套用尚未完成的控制項草稿。至少保留一份 Profile 及每份 Profile 的最後一個 Mode。

「複製」建立獨立副本並進入命名狀態；複製 Mode 不帶原模式已佔用的模式觸發控制項。「＋」建立空白映射，新 Profile 內含一個空白 Mode，力度曲線預設 Linear；新 Mode 不指定模式觸發控制項，燈光採預設值。新增或複製後取消改名仍保留新項目。

畫布與 Inspector 放在同一工作區，寬視窗並排；Inspector 內容過長時可獨立捲動，窄視窗改為上下排列。右側 Inspector 分為「Mode 設定」與「控制項設定」，切換分頁保留映射草稿。Mode 設定收納模式觸發控制項、Pad 模式燈色及本模式共用亮度；「目前觸發控制項」可直接選擇 Pad 或具燈號的一般按鍵，變更即儲存，「✕」清除指派；其他 Mode 已佔用的項目標示所屬 Mode 並停用。控制項不得被其他模式重複佔用，也不能使用模式選擇鍵、SHIFT／FAVORITES／BROWSER 或不具一般按鍵燈號的 Encoder／Strip 控制項。一般按鍵為單色燈，不提供 Pad 燈色選擇；按住模式選擇鍵時，已指派的目前模式按鍵高亮，其餘已指派模式按鍵微亮，選模式的按下／放開不輸出原本 MIDI。模式選擇鍵由整份 Profile 共用，保留在上方 Mode 工作列。

切到「Mode 設定」時，參照圖顯示模式指派預覽：Pad 顯示 Mode 名稱與模式色，按鍵顯示單色燈，編輯中的模式高亮，其他已指派模式微亮，未指派項目淡化。點已指派的控制項會切換右側編輯對象；點未指派項目會顯示其未指派狀態並保留目前編輯 Mode，不會自動綁定。進入 Mode 設定時，若目前選取的控制項已有對應模式且沒有草稿／改名，會直接顯示該模式。

模式瀏覽不儲存 Profile、不釋放按住的音符、不發 MIDI／HID，實體 LED 仍由 Runtime 管理。切回「控制項設定」恢復該編輯模式的 MIDI 預覽與草稿。實體切換模式仍透過硬體模式選擇鍵；在 Mode 設定或有映射草稿時，硬體切模式不覆蓋編輯對象；乾淨的控制項編輯器仍會跟隨硬體模式切換。

匯出會下載可攜 JSON；匯入會儲存為本機的新設定檔，不包含 MIDI 輸出埠或瀏覽器物件。目前 Profile 仍是 [Mikro 專用格式](devices/mikro-mk3/profile.md)，不代表已支援跨裝置載入。

## 擷取與研究

在 Testing 選取控制項，依提示操作實體控制器，按「開始擷取」及「停止並分析」保存樣本與候選欄位。操作備註可補充當時動作與裝置狀態；候選只表示有變化，需重複操作確認協定。

原始資料最多保留 100,000 筆，畫面顯示最近 100 筆。「暫停顯示」或「清除顯示」不刪除 Session，也不中止 MIDI 轉譯。Session 不會自動儲存，重新整理前先匯出；匯入會取代目前 Session。格式與限制見[開發指南](development.md#capture-session目前-hid-擷取格式)。

## 音符釋放

目前網頁在切換模式、套用設定、切換 MIDI 埠或控制器斷線時，會釋放相關音符與按住的 CC；「Panic」可主動釋放目前狀態。重新整理也會嘗試釋放。實體 MIDI 埠消失時，最後的 Note Off 可能無法送達；若仍有聲音，請使用接收軟體的 Panic。

MiDiY 不會建立虛擬 MIDI 埠或修改接收 App 的 MIDI map。接收端方式與驗證範圍見[支援表](support.md#midi-輸出與接收端)，Mikro 的 Logic Pro／Koala 設定範例見[裝置指南](devices/mikro-mk3/user-guide.md#midi-接收端範例)。
